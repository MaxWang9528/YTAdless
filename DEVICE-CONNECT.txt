iPhone: switching between WSL (xtool) and Windows (Apple Devices)
=================================================================

The phone can be used by only one side at a time. Plug it in and unlock it.
Its BUSID is 2-2 (check with `usbipd list`; it changes if you use another port).

One-time setup (Admin PowerShell):
    usbipd bind --busid 2-2

To WSL, for xtool (Admin PowerShell, then WSL):
    Stop-Service "Apple Mobile Device Service"
    usbipd attach --wsl --busid 2-2
    sudo pkill usbmuxd; sudo usbmuxd
    xtool devices                       # then: xtool dev run

To Windows, for Apple Devices or Files (Admin PowerShell):
    usbipd detach --busid 2-2
    Start-Service "Apple Mobile Device Service"
    Then replug the phone.

If attach says "Device busy" (Windows still has the phone):
    usbipd bind --busid 2-2 --force     # for xtool
    usbipd unbind --busid 2-2           # undoes it so Apple Devices works,
                                        # then redo the one-time setup

Notes: tap "Trust" on the phone if asked. Re-attach after unplugging the phone,
restarting it, or restarting WSL.
