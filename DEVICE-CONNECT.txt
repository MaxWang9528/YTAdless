Getting WSL to see the iPhone (for xtool dev run)
=================================================

Symptom: `xtool dev run` is stuck on "waiting for device", or `xtool devices`
hangs or lists nothing.

Cause: the iPhone is connected to Windows but not attached to WSL, or the
usbmuxd daemon isn't running in WSL. The attachment drops whenever the phone
is unplugged or reboots, or WSL restarts (`wsl --shutdown`, a Windows reboot).


Fix (run these in WSL)
----------------------

1. Plug in the phone and unlock it.

2. Find the iPhone's bus ID:

       usbipd.exe list

   Look for "Apple Mobile Device USB Composite Device" (VID:PID 05ac:12a8).
   Its BUSID looks like 2-2. It can change if you use a different USB port.
   Its STATE should be "Shared". If it says "Not shared", see "First-time
   setup" below.

3. Attach it to WSL (use your BUSID):

       usbipd.exe attach --wsl --busid 2-2

4. Start usbmuxd:

       sudo usbmuxd

   If it says it's already running, restart it:

       sudo pkill usbmuxd; sudo usbmuxd

5. If the phone asks "Trust This Computer?", tap Trust and enter your passcode.

6. Check that xtool sees the phone:

       xtool devices

   Then install:

       xtool dev run


First-time setup (only if STATE is "Not shared")
-----------------------------------------------

In an *Administrator* PowerShell on Windows:

    usbipd bind --busid 2-2 --force

After that, step 3 works without admin rights.


Still stuck?
------------

- Unplug and replug the phone, then repeat steps 2-4.
- If attach fails, run `wsl --shutdown` in PowerShell, reopen WSL, and repeat
  steps 2-4.
- Make sure the Apple Devices app (or iTunes) isn't syncing the phone at the
  same time.
- The phone must stay unlocked while xtool installs the app.
